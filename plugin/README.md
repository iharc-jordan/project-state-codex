# Project State payload for Codex

The independent Codex adaptation of Atomic 47 Labs Project State includes core
project and grant workflows, SR&ED, Tender, Intel, Portfolio, Research, work-type
packs, reporting, scheduling, fanout, and local HTML snapshots.

Install or update as `project-state@personal` using the instructions in the
[repository README](../README.md). The Codex manifest discovers `skills/` and
registers the bundled checked Node MCP server. Read [CODEX.md](./CODEX.md) once
when a Project State skill first runs in an active task.

Installation provides available workflows; project capabilities, configured
connectors, paid entitlements, migrations, recurring jobs, and publishing remain
governed by project configuration and explicit requests. Existing facilities
retain their data and optional fields.

The upstream baseline is documented in [upstream.json](../upstream.json).
